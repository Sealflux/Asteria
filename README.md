# Asteria
A game about balancing sacrifice and information

In this game made for Horizons Polaris, a group of Starseekers set out on a journey to explore the dark forest, avoiding traps and navigating invisible mazes along the way. 
## Demo On Itch
[**Link**](https://sealflux.itch.io/asteria)
## Controls
Move with arrow keys or WASD. 
## Prompt
This game was inspired by the prompt: What falls may illuminate the way forward.
We interpreted this as how death allows yourself to progress further. This is the core game mechanic of our game, where characters drop lanterns when they meet their demise, lighting the way for future travellers.
## Two Line Slogan
To progress, you must die,
Illuminate where hope lies!
